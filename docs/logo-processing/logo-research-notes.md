# UI/UX Logo Optimization Research Notes

## Website Header Logo Standards (Looka.com)

### Recommended Dimensions:
- **Vertical layout:** 160 x 160 pixels
- **Horizontal layout:** 
  - 250 x 150 pixels
  - 350 x 75 pixels
  - 400 x 100 pixels
- **Average height:** 20-30px (some sources say 40-70px including padding)

### Favicon Sizes:
- 16 x 16 pixels
- 32 x 32 pixels
- 48 x 48 pixels

### Key Principles:
1. Logo should be present on every page (typically left side of navigation)
2. Use PNG for web (lossless compression)
3. Keep file size under 200KB for fast loading
4. For circular crops (social media), use icon/monogram version

### Social Media Profile Photos:
- Instagram: 110 x 110px (circular)
- Facebook: 180 x 180px (square, cropped to circle)
- YouTube: 800 x 800px (circular)
- Twitter: 400 x 400px (circular)
- LinkedIn: 400 x 400px (circular)

### Email Signature:
- Max width: 320px
- Height: 70-100px
- File size: under 10KB

## Clear Space / Whitespace Guidelines (Medium - Koko)

### Key Principles:
1. **Clear space protects visual impact** - no other elements can occupy this space
2. **Clear space defines minimum room needed** - logo + clear space = total required space
3. **Use a minimum unit "x"** based on logo elements (letter, x-height, logomark)

### Methods to Define Clear Space:
1. **Single letter** - e.g., Google uses "G" as unit
2. **x-height** - height of lowercase letters (smaller clear space)
3. **Logotype height** - entire height of text (good for all-caps)
4. **Logomark** - use the icon/symbol as unit (Slack, Microsoft)
5. **Elements of logomark** - extract a shape from the icon
6. **Details** - McDonald's uses width of M's foot

### Best Practices:
- Tighter internal spacing = smaller clear space needed
- Looser/dispersive letters = larger clear space needed
- Clear space should exceed spacing between logomark and logotype
- Use whole numbers or easy ratios (don't make people do math)
- Use iconic brand elements as "x" for consistency

### General Rule:
- Minimum 30 pixels OR 1/4 of logo height from surrounding elements
- 20% of logo size is common minimum whitespace (TU Delft)
- 0.25 inches minimum for print applications

## Responsive Logo Breakpoints:
- Mobile: 320px - 480px
- Tablet: 481px - 768px  
- Small Desktop: 769px - 1024px
- Desktop: 1025px+

### Responsive Logo Strategy:
- Full logo (icon + text) for desktop
- Icon-only for mobile/small screens
- Consider simplified versions at smaller sizes


## Navbar Height Standards (Prototypr)

### Real-World Examples:
- BBC: 41px
- CNN: 41px
- LinkedIn: 52px
- Instagram: 54px

### Recommendations:
- **64px** is a comfortable navbar height (accommodates logo + room for navigation)
- News sites use smaller navbars (40-45px) to maximize content space
- User-oriented platforms use icons instead of text in navigation
- Mobile navbars often use icon-only navigation

## Summary: Optimal Logo Dimensions

### Header Logo:
- **Height:** 32-48px (within 64px navbar)
- **Width:** Proportional, typically 100-200px for horizontal logos
- **Icon-only:** 32-48px square

### Full Logo (Hero/Footer):
- **Width:** 200-400px
- **Height:** Proportional

### Favicon:
- 16x16, 32x32, 48x48px

### Clear Space:
- Minimum 1/4 of logo height on all sides
- Use logo element (letter or icon) as measurement unit
